# 大字牌 (Bombastic Big Signs)

一个 Forge 1.20.1 模组：添加会显示**一个大字**的告示牌。

放置方式和原版告示牌一样（可插在地上或挂在墙上），但它只保留一个字符——一个汉字或一个字母/数字——并放大到铺满整个 16×16 牌面，适合做招牌、路标、指示牌。

## 特性

- **站立牌**：16 个朝向（22.5° 步进），插在方块上
- **墙面牌**：4 个朝向，挂在墙上
- **超大字形**：汉字等比放大约占牌面 73%，字母/数字与汉字笔画粗细一致
- **多人支持**：服务端校验编辑距离（8 格内），文字实时同步给周围玩家
- **原版交互兼容**：
  - 16 色**染料**改变文字颜色
  - **荧光墨囊**发光文字 / **墨囊**恢复
  - **蜂蜜脾**（打蜡）后禁止编辑，创造模式豁免

## 合成配方

```
棒 棒 棒
棒 板 棒
棒 棒 棒
```

周围一圈 8 根**木棒**，中间 1 块**任意木板**（任何原木品种均可）→ 合成 1 个大字牌。

## 使用方法

1. 合成大字牌后放置（与原版告示牌相同的放置规则）
2. **右键**打开编辑界面，输入**一个字符**，回车确认
3. 手持染料/荧光墨囊/墨囊右键可改变文字样式；手持方块右键会正常放置方块（不会打开编辑界面）
4. 持蜂蜜脾右键打蜡，蜡封后无法再编辑

## 安装

- Minecraft **1.20.1** + Forge **47.x**
- 把 `bigsign-1.0.0.jar` 放进 `.minecraft/mods/`（客户端和服务端都要装）

## 构建

```bash
./gradlew build
```

产物位于 `build/libs/bigsign-1.0.0.jar`。需要 JDK 17。

## 技术说明

站立牌的 16 向旋转无法用 blockstate 表达（Minecraft 的 blockstate `y` 旋转仅支持 90° 倍数），因此站立牌的牌板由 BlockEntityRenderer 手动绘制——与原版告示牌的实现方式一致。文字更新使用自定义网络通道（原版 `ServerboundSignUpdatePacket` 需要服务端 `openTextEdit()` 授权，自定义编辑界面无法满足该限制）。
